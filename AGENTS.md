# Personal dotfiles

This repository contains my personal dotfiles. Keep changes small and focused
on the requested behavior.

Adding or updating documentation (such as README.md) or writing new tests is
usually unnecessary for routine dotfile changes. Do so when explicitly requested
or when it provides clear value for a substantive change, such as complex helper
scripts or installer behavior. Avoid adding documentation or tests merely to
accompany a configuration edit.

Still review changes for correctness and run relevant existing checks when
appropriate. Scale validation to the scope and risk of the change.
